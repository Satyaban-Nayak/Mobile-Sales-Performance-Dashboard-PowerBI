# 📊 Mobile Sales Performance Dashboard – Power BI Project  

An interactive **Power BI dashboard** built to analyze **multi-brand mobile sales performance** across different cities, months, and payment methods.

---

## 🧩 **Project Overview**
This dashboard provides in-depth insights into:
- 💰 **Total Sales, Quantity & Transactions**
- 🌆 **Sales by City and Month**
- 💳 **Payment Method Distribution**
- ⭐ **Customer Ratings Funnel**
- 🏷️ **Top Performing Brands and Models**

---

## 🛠️ **Tools & Technologies Used**
- **Microsoft Power BI**
- **Power Query** → Data cleaning & transformation  
- **DAX Measures** → Calculated KPIs (Sales, Quantity, Averages, etc.)  
- **Visualizations:** Cards, Slicers, Map, Line Chart, Pie Chart, Funnel, Table  
- **Interactive Filters** for dynamic data exploration  

---

## 🎨 **Dashboard Highlights**
✅ Brand & Model-wise filtering  
✅ Month & City slicers for detailed insights  
✅ Map visualization for city-based performance  
✅ Funnel chart for customer ratings  
✅ Top-3 mobile models visualization  
✅ Clean, colorful, and user-friendly design
